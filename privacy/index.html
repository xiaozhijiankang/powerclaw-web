PowerClaw 隐私政策

更新日期：2026-10-13

本政策适用于由北京贰零贰零科技发展有限公司（以下简称“我们”）运营的 PowerClaw 中国大陆版。隐私事务联系邮箱：support@erlingerling.com。

一、你的选择

首次启动时，你可以阅读本政策及用户协议，自主选择是否同意。

不同意不会阻止你使用离线基础训练：查看内置动作要点、计时和记录当前页面的组数均无需登录，也不会上传训练数据。

基础模式的计时和组数在离开页面后清除。

查看协议无需登录。为展示最新协议，应用会连接国内服务器获取文档，服务器会接收完成网络连接所必需的 IP 地址等信息。你的隐私选择和已同意的协议版本保存在本机。选择基础模式后，再次打开应用不会自动联网获取协议；你可以主动选择重新查看。

二、我们处理哪些信息、用于什么目的

  1. 账号与微信登录：当你主动选择微信登录并在微信中授权后，我们接收授权结果、微信账号标识（OpenID，及微信返回时的 UnionID）、授权范围内的昵称和头像，用于建立账号、识别登录身份和展示个人资料。我们不会获取你的微信密码、聊天记录或通讯录。拒绝微信授权不影响离线基础训练。 iOS 版还支持你主动选择“通过 Apple 登录”，我们接收 Apple 提供的应用专属用户标识、身份令牌及你授权的姓名、邮箱（可能为隐藏邮箱），用于验证身份和建立账号，不获取 Apple 账号密码。
  2. 个人资料与训练服务：你主动填写的昵称、年龄、性别、身高、体重、训练目标、经验、时间安排、器械条件，以及训练动作、组数、次数、重量、主观用力程度和备注，用于展示记录、跨设备同步和生成个性化训练建议。“训练地点”指你选择的健身房或家庭等训练条件，不代表读取 GPS 定位。
  3. 健康相关内容：你填写的伤病、身体限制，以及对话中主动提供的医疗健康信息，可能属于敏感个人信息。处理这些内容可能影响你的隐私和个人权益，请谨慎提供，不要上传身份证件、病历原件或他人健康资料。离线基础训练不要求此类信息；不提供相关内容会使个性化建议缺少相应参考。
  4. AI 教练与计划：你主动发送的对话、模型回复，以及生成建议所需的个人资料和训练上下文，会由服务端保存并提交给下列国内模型服务，供生成回复、计划和保持对话连续性。AI 输出可能不准确，不属于医疗诊断或治疗建议。
  5. 头像与相册：仅当你主动更换头像时申请相册访问权限，处理你选择的图片。你可拒绝该权限或在系统设置中撤回；拒绝不影响其他训练功能。
  6. 运行与安全信息：使用联网功能时，服务可能接收 IP 地址、请求时间、接口及错误信息、应用版本、系统平台、语言和时区，用于提供服务、故障排查和安全防护。
  7. iOS 消息通知：在你登录并允许系统通知后，我们处理苹果分配的设备推送标识，并将其与当前账号关联，用于向该设备发送服务通知。国内服务通过 Apple 推送通知服务（APNs）投递；你可以在 iOS 系统设置中关闭通知，拒绝不影响其他训练功能。

当前国内版未开放会员支付，不处理支付账号、银行卡或交易信息；未接入第三方广告服务。我们不因你拒绝可选权限而限制无关功能。

三、第三方 SDK 与服务清单

Apple 推送通知服务（APNs，仅 iOS）

  • 提供方：Apple Inc.。
  • 用途和触发：登录后，经你允许系统通知，用于投递服务通知。
  • 处理信息：设备推送标识、应用标识，以及通知标题、正文和用于打开对应页面的必要数据。通知不附带完整训练记录、健康资料或教练对话。
  • 管理方式：可在 iOS 系统设置中关闭通知；退出登录、撤回同意或切换服务区时，应用停止当前服务区的推送注册并请求解绑。
  • Apple 隐私政策

微信 Open SDK

  • 提供方：深圳市腾讯计算机系统有限公司。
  • 用途和触发：你主动使用微信登录时，通过微信客户端完成授权；并非同意隐私政策后自动登录。
  • 处理方式和信息：SDK 与微信客户端交互，处理应用身份及授权请求；我们通过服务端接口接收授权码、账号标识和你授权的昵称、头像。微信侧的具体处理范围和管理方式见其规则。
  • 平台差异：Android 在调用时验证微信的安装状态；iOS 为适配登录读取设备型号并保存在本地，并可能通过系统剪切板传递授权相关信息。
  • 微信 Open SDK 个人信息处理规则。

腾讯云

  • 提供方：腾讯云计算（北京）有限责任公司。
  • 用途：为应用提供网络服务，保存和传输账号信息、训练记录、对话及相关文件。
  • 处理方式和信息：通过云服务器、数据库和文件存储服务，处理上述业务信息，以及 IP 地址、访问记录等提供服务所必需的信息。
  • 腾讯云隐私保护声明。

通过 Apple 登录（仅 iOS）

  • 提供方：Apple；用于你主动选择的 Apple 账号授权登录。
  • 处理方式和信息：系统授权界面与 Apple 服务交互；我们接收应用专属账号标识、身份令牌和授权范围内的姓名、邮箱，在国内服务验证身份。Apple 在授权登录过程中如何处理信息，请参阅下方《通过 Apple 登录与隐私》。
  • 通过 Apple 登录与隐私。

Firebase Crashlytics（仅 iOS）

  • 提供方：Google LLC；用途为发现崩溃、分析故障和改善稳定性，不用于广告。
  • 触发和方式：同意当前服务区的隐私政策后，初始化 SDK 并启用自动上报。SDK 在设备上记录诊断信息，经网络发送至 Google 的 Firebase 服务。Android 国内安装包不包含此 SDK。
  • 信息范围：应用版本、设备型号、操作系统、内存和磁盘等运行状态，崩溃时间、线程堆栈、异常信息，以及 SDK 生成的安装和会话标识；网络连接还会涉及 IP 地址等技术信息。我们另行记录服务区、账号所属区、商店对应地区及切区状态，不向 Crashlytics 设置账号 ID、邮箱或登录令牌。
  • 日志范围：报告可能附带故障前的操作日志。使用国际服务区期间产生的 Analytics 操作摘要可能包含页面、登录方式、训练时长、组数及训练量、对话标识及消息长度、订阅状态等；切回国内服务区不会追溯清除已有诊断日志。我们不主动将对话正文、密码或完整训练记录作为自定义诊断字段发送。
  • 存储地点和期限：诊断信息会传输至 Google 的全球基础设施，涉及境外处理，不能通过服务区标签限制在中国大陆存储。按 Firebase 的说明，崩溃堆栈及相关标识保留 90 天后开始从在线和备份系统中移除。
  • 撤回：可在隐私政策页面撤回同意。应用会关闭自动上报；受 SDK 机制影响，iOS 关闭设置在下次启动生效，不能保证当次运行立即停止本地记录。以后重新同意并启用时，可能补传本地保存的报告。
  • Firebase 隐私与安全说明；Crashlytics 日志与上报控制说明。涉及信息权利请求时，可通过本政策的联系邮箱向我们提出。

智谱大模型开放平台

  • 提供方：北京智谱华章科技股份有限公司。
  • 用途和触发：你使用 AI 教练或计划生成功能时生成回复或训练建议。
  • 处理方式和信息：通过服务端 API 提交当前请求、必要的对话历史、训练记录和个性化资料；不会为此提交微信登录凭据。请勿在对话正文中输入不必要的身份、联系方式或敏感资料。
  • 智谱大模型开放平台隐私政策。

DeepSeek 备用模型服务

  • 作为可选的备用 AI 服务，仅在我们已启用该服务且主要 AI 服务暂时不可用时，用于完成你的请求；未启用时不会向其发送你的信息。
  • 用途、方式和信息：通过服务端 API 处理该次 AI 请求及必要上下文，以完成原请求，不增加新的业务目的。
  • 提供方及其信息处理规则见 DeepSeek 隐私政策。

我们按功能需要向上述服务传输信息，不出售你的个人信息。涉及新增处理目的、第三方或依法需要单独同意的处理时，应另行告知并取得相应授权；本政策不替代具体场景依法需要的单独同意。

四、存储与保护

我们用于保存国内账号信息、训练记录和对话等业务数据的服务器部署在中国大陆。iOS 崩溃诊断信息由上述 Firebase Crashlytics 服务在 Google 的全球基础设施处理，涉及境外传输与存储；其他第三方的处理方式见本政策第三部分。涉及向境外提供个人信息时，应履行适用的告知、授权及其他法定程序，本政策不替代依法需要的单独同意。

我们以实现上述目的所需的最短时间保存信息，并结合账号状态、用户请求及适用的法定保存义务确定期限。不再需要保存的信息应删除或匿名化；依法需要保留的，应限制为必要的存储和安全保护用途。我们采取访问控制、传输保护等措施，但网络和信息系统无法保证绝对安全。发生个人信息安全事件时，我们将依法采取补救和告知措施。

五、查阅、更正、撤回与注销

你可以在个人资料和训练页面查看、修改支持编辑的信息，在系统设置中管理相册权限，在 App 的隐私政策页面选择“撤回同意并进入基础训练”。撤回后停止发起账号和同步等业务请求；已经发出的请求无法追溯撤销。iOS 崩溃诊断的关闭生效时间及本地报告处理方式见第三部分。撤回不影响撤回前基于授权进行的处理，也不会自动删除此前已上传的数据。

你可在 App 的个人设置中申请注销账号。

当前注销会停用账号并清除登录会话，不等同于立即物理删除全部历史记录。

如需查阅、复制、更正或删除其余个人信息，或对处理结果有异议，请联系 support@erlingerling.com。我们会核验请求人身份，仅要求核验所必需的信息，并依法处理和回复；如依法不能满足请求，会说明原因。请勿通过邮件发送密码或完整身份证件。

六、未成年人

未成年人应在监护人指导下阅读本政策并使用适合自身的训练内容。未满十四周岁用户请使用无需账号的离线基础训练，不应自行向账号、对话等联网功能提交个人信息。监护人发现相关个人信息被提交时，可通过上述邮箱联系处理。

七、政策更新与联系

本政策可在 App 内查看。对于已同意使用联网服务的用户，隐私政策或用户协议更新后，我们会在你再次打开应用并获取到新版本时提示你阅读，重新选择是否同意。不同意仍可使用离线基础训练。已选择基础模式的用户，可主动重新查看协议。
